client
1. Зробити сторінку логуквання для Персоналу/Адмін
2. Сторінка з популярними спецеалістими дані з бекенду.
3. Сторінка Tests висвітлення даних, та блок з завантаженням даних.

server
1. Зробити логуванння для клієнтів +
2. Зробити логуквання для Персоналу/Адмін +
3. Зробити сесію для користувачів +
4. Популярні спецеалісти
5. Зробити завантаження даних в Supabase, та додати висвідлення списку даних. +
6. Вивід даних клієнта та Персоналу.
7. Дані про візити.


--- GitHub and Git ---
git checkout main
git pull origin main  (Переключитися на main та скачати всі нові дані)

git checkout feature/[name] (Створити нову гілку та переключитися на неї, після чого працювати у ній, за потреби можна зробити оновлення даних з main)
git merge main (Робити тільки після завершення роботи, краще всього робити у самому гітхабі)
